Project Overview

This project analyzes behavioral engagement patterns across an online mental health assessment platform to understand what drives teletherapy signup conversion, where users abandon the conversion journey, and which behavioral patterns represent opportunities for product optimization.

The work evolved from exploratory conversion analysis into a production-style analytics architecture incorporating dimensional modeling, identity resolution, behavioral feature engineering, statistical modeling, funnel analysis, and executive analytics.

Technology Stack

Data Platform

Google BigQuery and dbt for cloud warehousing, transformation, testing, and documentation.

Data Modeling

SQL, dimensional modeling, and Medallion Architecture across staging, intermediate, and analytical layers.

Statistical Analysis

Python, pandas, scikit-learn, statsmodels, and scipy for feature engineering and statistical inference.

Visualization

Tableau dashboards for interactive EDA, behavioral funnel analysis, and product optimization insights.

Behavioral Analytics

Funnel analysis, abandonment analysis, psychological-domain taxonomy, and behavioral feature engineering.

Identity & Data Quality

Visitor identity resolution, relationship validation, bot filtering, and reliable behavioral attribution.

Statistical Modeling

Statistical methods were used to distinguish meaningful relationships from differences in observed conversion rates.

Chi-Square Analysis

Used to identify statistically significant relationships between categorical behavioral variables and signup conversion.

Logistic Regression

Used to estimate odds ratios for behavioral and visitor characteristics associated with signup conversion.

Technical Challenge: Multicollinearity

Initial regression models exhibited unstable coefficients caused by structural multicollinearity among overlapping behavioral features such as engagement state, tests taken, and tests completed. Reference categories were redefined, redundant predictors were removed, and engagement and domain variables were separated to restore model interpretability.

Data Privacy & Responsible Use

This project uses privacy-preserving analytical representations. No personally identifiable information, raw IP addresses, or production user-level identifiers are included in the repository. The project demonstrates analytics engineering and behavioral modeling techniques without exposing sensitive production data.
